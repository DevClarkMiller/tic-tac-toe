# 1. Introduction

## 1.1 Overview

This project is an online tic-tac-toe experience which allows for multiplayer connections along with an AI mode as well for when you have nobody to play with.

---

## 1.2 Features

- ✅ AI Mode - Play against a bot with multiple difficulties.
- ✅ Online Multiplayer - Compete against your friends from all over the world.
- ✅ Chatting - Chat with your friends while you compete.
